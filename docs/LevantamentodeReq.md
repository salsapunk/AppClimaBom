# Levantamento de Requisitos

### 1.

Este documento descreve os requisitos funcionais e não funcionais do “Aplicativo de Clima” para mais informações acesse o read.me do repositório

### 2. Requisitos Funcionais (RF)

| Código | Descrição |
| --- | --- |
| **RF01** | O sistema deve permitir buscar o clima por cidade. |
| **RF02** | O sistema deve exibir dados como temperatura, umidade, vento e sensação térmica. |
| **RF03** | O sistema deve emitir alertas meteorológicos. |
| **RF04** | O sistema deve apresentar previsão para até 5 dias. |
| **RF05** | O sistema deve permitir alternar entre °C e °F. |

### 3. Requisitos Não Funcionais (RNF)

| Código | Descrição |
| --- | --- |
| **RNF01** | Responder em até 3 segundos. |
| **RNF02** | Alta disponibilidade (99%). |
| **RNF03** | Interface responsiva e intuitiva. |
| **RNF04** | Utilizar API meteorológica confiável |

### 4. Backlog de Prioridades

| Prioridade | Funcionalidade | Tipo |
| --- | --- | --- |
| 🟥 Alta | Clima atual, busca por cidade, alertas | RF |
| 🟨 Média | Previsão 5 dias | RF/RNF |
| 🟩 Baixa | Escolha °C/°F, histórico | RF |
